FastShare

Ek hi Wi-Fi pe Mac, Windows, Android aur iPhone ke beech full speed file transfer. Koi cloud nahi, koi signup nahi, koi size limit nahi — sab kuch aapke local network pe.

Download

💻
macOS macOS 14+ · Apple Silicon + Intel (universal)
⬇ Download .dmg .zip
Pehli baar khulte waqt: macOS "unidentified developer" bol sakta hai (app notarized nahi hai). Fix: app pe right-click → Open → Open. Ya terminal me ek baar: xattr -dr com.apple.quarantine /Applications/FastShare.app
🪟
Windows Windows 10 / 11 · 64-bit · standalone (kuch install karne ki zarurat nahi)
⬇ Download .exe
Pehli baar chalane par: Windows Firewall ek prompt dikhayega —"Allow access" pe click karo (private networks ke liye). Isse phone/PC connect kar payenge. Zip se nikaal kar FastShare.exe double-click karo.
🤖
Android App ki tarah install karo — icon + fullscreen, koi Play Store nahi
Install karne ka tarika: is page ko Chrome me kholo → ⋮ menu → "Add to Home screen" / "Install app". Icon home screen pe aa jayega aur fullscreen khulega.
Agar button upar "Install app" nahi dikha raha, to menu wala tarika pakka kaam karta hai.
🍎
iPhone / iPad Safari se — koi app install karne ki zarurat nahi
Safari me host ka page kholo → Share button → "Add to Home Screen". Icon lag jayega aur app ki tarah khulega.

Kaise chalta hai

  1. Ek device pe app chalao — Mac pe FastShare.app, ya Windows pe FastShare.exe. Ye "host" ban jata hai aur apna folder share karta hai.
  2. Baaki sab usi Wi-Fi pe rakho — aur kuch nahi karna.
  3. Host ki screen ka QR scan karo (ya link browser me kholo) — page khul jayega.
  4. Transfer karo — file/folder download karo, ya apne phone se file upload karo. Dono taraf full speed, kyunki data seedha local Wi-Fi pe jata hai.

Apna host kholo

Is page se seedha host ke page pe jaane ke liye address daalo (jaise 192.168.1.5 ya 192.168.1.5:8080). Wahi address host app ki screen pe aur QR me dikhta hai.

Details

SpeedWi-Fi ki maximum speed. Data kabhi internet ya server pe nahi jata — device se device seedha.
Size limitKoi limit nahi. Files streaming se jati hain, memory me poori load nahi hoti.
FolderFolder pe tap karo → poora ZIP ban kar download ho jata hai (subfolders ke saath).
UploadPhone/PC se host pe — drop-zone pe drag karo ya files chuno. Live speed + ETA dikhta hai.
Connected devicesWeb page aur host app dono me live list — kaun juda hai, kaun kitna bhej/le raha hai.
InternetZarurat nahi. Sirf local Wi-Fi/hotspot hona chahiye, dono devices pe same network.
SecuritySharing sirf aapke network tak. Jo bhi us Wi-Fi pe hai woh connect kar sakta hai — public Wi-Fi pe dhyan rakho.
